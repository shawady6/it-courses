## الاستخدام
حمّل الملف وافتحه في المتصفح، ومفيش اعتماد على أي مكتبات خارجية. أو شغّل GitHub Pages (Settings → Pages → `main` / root) وافتح `/<course>/`.

## تنبيه
الـ Labs والأكواد **ما اتجربتش على أجهزة فعلية**. مسارات القوائم والأوامر بتختلف حسب الإصدار، فجرّبها في Lab الأول.

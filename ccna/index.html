Module 1 — Network Fundamentals

1.1 ما هي الشبكة؟ What is a Network?

الـ Network هي مجموعة أجهزة (Hosts / End Devices) متوصلة ببعض عن طريق أجهزة وسيطة (Intermediary Devices) ووسائط نقل (Media) عشان تتبادل بيانات. الجهاز اللي بيطلب خدمة اسمه Client واللي بيقدمها اسمه Server.

3.3 طريقة الـ Subnetting خطوة بخطوة

القوانين:
• عدد الـ Subnets = 2^n (n = Bits المستعارة من الـ Host).
• عدد الـ Hosts = 2^h − 2 (h = Bits المتبقية للـ Host؛ ناقص Network ID و Broadcast).
• Block size (Magic number) = 256 − قيمة الـ Octet المهم في الـ Mask.

مثال: قسّم 192.168.10.0/24 على 4 Subnets

  1. محتاجين 4 Subnets → 2^2 → نستلف 2 bit → الـ Mask الجديد /26 = 255.255.255.192.
  2. Block size = 256 − 192 = 64.
  3. Hosts لكل Subnet = 2^6 − 2 = 62.

3.4 الـ VLSM والـ Summarization

VLSM (Variable Length Subnet Mask) معناها تقسّم بأحجام مختلفة حسب احتياج كل شبكة: ابدأ من الأكبر للأصغر عشان تتفادى التداخل. نستخدم /30 للـ Point-to-point links (Host 2 بس).

Route Summarization

دمج أكتر من شبكة في Route واحد. مثال: 192.168.0.0/24 + 192.168.1.0/24 + 192.168.2.0/24 + 192.168.3.0/24 ← 192.168.0.0/22 (لأن الثالث Octet: 0-3 = Block 4 = /22).

! خطوات:
! 1) اكتب الـ Octet المختلف بالـ Binary: 0=00000000 .. 3=00000011
! 2) عدّ الـ Bits المتطابقة من اليسار: 6 bits → 16+6 = /22

  • TTL (Time To Live): بينقص 1 عند كل Router. لو وصل 0 → الـ Packet بيتمسح ويرجع ICMP Time Exceeded (ده أساس الـ traceroute).

  • Socket = IP + Port. الـ Session تتحدد بـ (Src IP, Src Port, Dst IP, Dst Port, Protocol).

17.5.1 DNS التفصيل

  • هرمي: Root (.) → TLD (.com) → Authoritative (example.com).
  • الـ Resolver (Recursive) بيسأل ويخزّن في الـ Cache حسب الـ TTL.
  • الأدوات: nslookup و dig. ملف الـ Hosts المحلي بيتفحص الأول.
  • DNS بيستخدم UDP 53 للاستعلامات العادية و TCP 53 لـ Zone transfer والردود الكبيرة.

17.5.2 DHCP التفصيل

  • الـ Lease: العميل بيجدد عند T1 = 50% من المدة (Unicast Renew) و T2 = 87.5% (Rebind Broadcast).
  • أهم الـ Options: 1 Subnet Mask • 3 Router • 6 DNS • 15 Domain • 51 Lease time • 66/150 TFTP Server (للتليفونات والـ APs) • 43 Vendor-specific (WLC discovery).
  • الـ DHCP Relay بيحط giaddr (عنوان الـ Interface) في الـ Packet عشان الـ Server يختار الـ Pool الصح.
  • DHCPv6: UDP 546 (Client) / 547 (Server).

قائمة الفحص (Verification Checklist)

  • SW1# show etherchannel summary → Po1(SU) • show spanning-tree → SW1 هو Root.
  • SW1# show interfaces trunk → Native 99 على كل الـ Trunks.
  • كل PC ياخد IP من الـ DHCP (ipconfig).
  • PC-Sales ↔ PC-IT ينجح • PC-Guest → PC-Sales يفشل • PC-Guest → Web (www) ينجح.
  • R1# show ip ospf neighbor • show ip route ospf • show ip nat translations • show access-lists.
  • PC-Branch ياخد DHCP عبر Relay ويوصل للـ Web (OSPF default route + PAT على R1).
  • SSH لـ R1 من PC-IT: ssh -l admin 192.168.20.1.
  • Port-Security: SW2# show port-security.

تطويرات اختيارية: أضف R3 + HSRP للـ Gateway • DHCP Snooping على SW2 • Syslog + NTP • IPv6 Dual-stack • ACL تمنع Telnet.

ملاحظة صدق: الـ ISP مفيهوش Route للـ 192.168.x.x لأن الـ PAT على R1 بيغيّر المصدر لـ 203.0.113.1 (Connected عند الـ ISP). ولو شغّلت الـ ping من Router الـ ISP نفسه للشبكات الداخلية هيفشل وده طبيعي.

  • STP Election: Root Bridge → Root Ports → Designated Ports → Blocking.

Module 1 — مقدمة عن Sophos ومنتجاتها

1.1 مين هي Sophos؟

Sophos شركة أمن معلومات بريطانية بتقدم حلول Cybersecurity للشركات: حماية الشبكة (Firewall)، حماية الأجهزة (Endpoint)، الإيميل، الـ Cloud، وخدمات الاستجابة المُدارة (MDR). نقطة القوة الأساسية عندها هي التكامل بين المنتجات فيما يسمى Synchronized Security: الـ Firewall والـ Endpoint بيتبادلوا حالة الأمان لحظيًا ويتصرفوا مع بعض.

1.3 الفرق بين الأسماء: XG / XGS / SFOS

  • SFOS (Sophos Firmware Operating System) = نظام التشغيل نفسه (الإصدارات: v18, v19, v20, v21, v22...). وبعض الإصدارات الحديثة فيها Maintenance Releases (MR).
  • XG = اسم الجيل القديم من الأجهزة/المنتج. XGS = الجيل الأحدث من الأجهزة (بمعالجات Xstream Flow Processor على الموديلات الأكبر).
  • الإصدار الأحدث وقت كتابة الكورس: Sophos Firewall v22 (متاح عمومًا، وبيتوزع على مراحل). من أهم ميزاته المعلنة: Health Check (مقارنة الإعدادات بـ CIS benchmarks) ومعمارية Next-Gen Xstream بعزل خدمات مثل الـ IPS وhardened kernel ومحرك Anti-malware جديد وTLS 1.3 للـ Admin. راجع Release Notes الرسمية قبل أي ترقية.

Module 3 — التنصيب والإعداد الأولي

3.1 خطوات التنصيب (Virtual)

  1. نزّل الـ Image من موقع Sophos (Home Edition أو Trial) المناسب لـ Hypervisor بتاعك (OVA/VMX/VHD أو ISO).
  2. أنشئ VM بـ 4 vCPU تقريبًا و 6 GB RAM أو حسب الـ Edition، وديسك حسب الصورة/الترخيص، وأكتر من Network adapter: واحد لـ LAN، وواحد لـ WAN، (وواحد لـ DMZ لو محتاج).
  3. شغّل الـ VM: لو ISO، هتلاقي معالج تنصيب بيحدد الديسك. بعد الإقلاع هتظهر شاشة الـ Console.
  4. الـ Interface الأول (Port1) هو الـ LAN وعليه IP افتراضي 172.16.16.16/24 وفي بعض الإصدارات بيتغيّر عن طريق الـ Console. الـ Port2 غالبًا WAN بـ DHCP.
  5. من جهاز Client في نفس الشبكة افتح: https://172.16.16.16:4444 لتبدأ الـ Setup Wizard.
لو الـ Client مش على نفس الـ Subnet: ظبط له IP ثابت 172.16.16.x/24 مؤقتًا، أو غيّر IP الـ LAN من الـ Console (1. Network Configuration).

3.4 تحديث الـ Firmware وعمل Backup

  • System → Backup & firmware → Firmware: Check for updates، Upload، Boot (فيه Active و Backup firmware — نظام Dual boot partitions للـ Rollback).
  • Hot-fixes: تحديثات سريعة من Sophos بتتنزل تلقائيًا (Pattern updates للـ IPS/AV/App signatures كمان).
  • Backup: Local / Mail / FTP / Sophos Central (Cloud backup). خد Backup قبل أي ترقية، وبعد أي تعديل كبير. الـ Backup بيحتفظ بكل الإعدادات (يمكن تشفيره بباسورد).
  • Restore على نفس الموديل (أو أحدث) — في بعض الحالات بيحتاج نفس الإصدار أو أقدم.

3.5 إعادة الضبط Reset

  • Reset admin password: من الـ Console: 2. System Configuration → Reset admin password (ما يتطلبش الباسورد القديم لكن بيحتاج Console access).
  • Reset to factory defaults: من الـ Console (System Configuration → Reset to factory defaults) أو زر Reset الفيزيائي على الأجهزة. بيمسح كل شيء.

7.2 أين تُنشأ؟

  • Protect → Rules and policies → NAT rules: قواعد مستقلة (من v18+). كل Rule فيها: Original source/destination/service ← Translated source/destination/service + Inbound/Outbound interface + Load balancing اختياري.
  • Default NAT: Default SNAT IPv4 Internet traffic (Masquerade) للـ LAN→WAN.
  • الـ Translated source = MASQ (IP الـ Outbound interface) أو IP محدد (Alias).
  • Load-balancing DNAT: توزيع على أكتر من Server (Round robin / Weighted / Failover).

9.2 الـ IPS Intrusion Prevention System

  • بيفحص الترافيك مقابل Signatures لثغرات وهجمات معروفة (Exploits, Scans, Brute force, Malware C2...). وبيتحدث تلقائيًا من SophosLabs.

9.3 الـ ATP Advanced Threat Protection

  • بيكتشف Botnets والـ Command & Control (C2) عن طريق: Threat intelligence من SophosLabs (قوائم IP/Domain/URL خبيثة) + DNS inspection + Web + IP reputation.
  • الـ Actions: Log only أو Log and drop. وبيظهر الـ Source (الـ Host المصاب) في Control Center → ATP و Log viewer → ATP.
  • مرتبط بالـ Security Heartbeat: لو Host مصاب، الـ Firewall بيعمل Alert/Action (لو الـ Endpoint متسجل) أو يستخدم Active Threat Response.

9.4 Zero-Day Protection (Sandstorm سابقًا)

  • الملفات المشبوهة (Executables, Office docs with macros, PDFs, Archives...) بتتبعت لـ Cloud sandbox وتتنفّذ فيها، ويتولّد Report (Static + Behavior). الـ Client بيستنى (Hold) أو ينزّل بعدين حسب الإعداد.

13.1 Email Protection

Appendix D — سيناريوهات Troubleshooting (حاول قبل ما تفتح الحل)

كل سيناريو: العرض ← فكّر في الخطوات ← افتح الحل. التمرين الحقيقي إنك تحدد أنهي Log/أداة هتبدأ بيها.
1) موظف بيقول "الإنترنت واقف" وباقي المكتب شغال. ابدأ: Log viewer بالـ Source IP. لو مفيش Log أصلاً ← مشكلة L2/DHCP/Zone (الجهاز مش واصل). لو فيه Denied ← شوف Rule ID (غالبًا Group/Policy أو Match known users وهو مش Authenticated). تأكد من Live users.
2) بعد تفعيل TLS inspection، تطبيق بنكي/Update بيفشل. Certificate pinning أو الـ CA مش Trusted. الحل: Rule فوق بـ Don't decrypt للـ Domain/Category، وراجع Log → SSL/TLS.
3) Site-to-Site VPN بيظهر Connected وPing مش شغال. افحص: (1) Firewall rules LAN↔VPN في الاتجاهين. (2) Local/Remote subnets متطابقة (Mirror). (3) Route للـ Remote subnet (Route-based). (4) NAT: ضيف NAT exemption لو الـ Masquerade بيترجم ترافيك الـ VPN.
4) نشرت Web server بـ DNAT، شغال من برا ومش من الداخل. Loopback/Hairpin مش معمول. أنشئ NAT rule (Source LAN → Dest Public IP → Translate Dest للسيرفر + SNAT) أو استخدم DNS داخلي يرجع IP السيرفر (Split-DNS) — الحل الأنظف.
5) DNAT معمول وصح، لكن الـ Server بيستقبل ومفيش رد. Asymmetric routing: Gateway السيرفر مش الـ Sophos. صحّح الـ Default gateway. تأكد بـ Packet capture من الاتجاهين.
6) Multi-WAN Failover مش بيحصل لما ISP الأول يقع. Gateway probe بيعمل Ping لـ IP الـ ISP نفسه (اللي لسه حي) بدل IP على الإنترنت. غيّر الـ Probe لـ IP بعيد (مثل 1.1.1.1) أو تحقق بـ HTTP/TCP. وشوف الـ Failover rule و Gateway weights.
7) CPU عالي ومستخدمين بيشتكوا من البطء. راجع: Rules اللي فيها IPS + AV + TLS على ترافيك داخلي ضخم (Backup/Replication). استثنِ الترافيك الداخلي، فعّل FastPath لما يكون مناسب، خفّض Logging، وراجع Live connections لأعلى استهلاك.
8) Heartbeat بيظهر Missing على Endpoint سليم. الجهاز مش مسجّل بنفس Central tenant، أو الـ Port 8347 مقفول بين الـ Endpoint والـ Firewall، أو Zone/Rule بتمنع. تأكد من التسجيل والـ Rule.
9) Captive Portal مش بيظهر على HTTPS sites. طبيعي: المتصفح مش هيحوّل HTTPS بدون تحذير. اختبر بـ HTTP أو افتح الـ Portal مباشرة (https://FW:8091).
10) مستخدم AD بيتعرف بـ STAS لكن Group Policy مش بتتطبق. الـ Groups مش مستوردة أو الـ Mapping بين AD Group واسم Group على Sophos غير مظبوط. راجع Live users وانتماء الـ Group.
11) IPS حجب Application شرعي بعد Update. Log → IPS → Signature ID → Exception (أو غيّر Action). وثّق السبب. راجع إعداد الـ Policy (Platform/Target) لتقليل False positives.
12) إيميلات بتتأخر / ما بتوصلش بعد تفعيل MTA. تحقق: MX/DNS • Route للـ Mail server • Port 25 مفتوح • Quarantine • Mail log (Log viewer → Email) • SPF/Reverse DNS لو بتتحجب عند المستقبل.
13) HA بيعمل Failover كل شوية. Monitored port بيرجّ/يقع، أو الـ HA link فيه مشكلة، أو Resources عالية. افحص Cabling وLog الـ HA.
14) Backup Restore فشل. Version/Model مختلف، أو الـ Backup مشفّر بباسورد غلط. استخدم نفس الـ Firmware ثم Restore.
15) Sophos Connect متصل لكن مفيش Internal DNS. SSL VPN global settings → DNS = LAN DNS + Suffix. وتأكد من Rule VPN→LAN تسمح بـ DNS (UDP/TCP 53).
